# 이동가이드 배치·보조 버튼·진동 패턴 — 2026-10-28 (KST)

기준: `feature/guidance-threshold-navigation-refresh-20261027` / `4f9956f81c6dea389e33c31936031a38e0048057`.

## 변경

- 현재 이동속도/승차점까지 두 요약 카드를 이동가이드 위로 이동했다.
- 속도와 `km/h`는 한 줄로 표시하며, 사용 가능한 폭에 맞춰 14~22sp로 크기를 조절한다. 기존 좁은 화면·큰 글자 환경의 세로 카드 배치는 유지한다. 기본 `0.0 km/h`와 실제 계산 입력을 구분하는 정책은 변경하지 않았다.
- 선택한 이동 안내의 시작/변경/종료 버튼을 이동가이드 바로 아래에 배치했다. 기존 실행 조건·콜백·권한·서비스 생명주기는 유지했다.
- 다른 경로 보기/접기, 현재 위치·경로 다시 확인, 기기 위치 설정을 아이콘+가운데 정렬 라벨의 전체 폭 박스형 버튼으로 변경했다. 터치 영역 최소 52dp, 같은 모서리·여백·색상을 사용한다. 기존 노출 조건과 기능은 그대로다.
- 카드 내부 버스 즐겨찾기 등록/해제와 검색창 아래 중복 버튼 제거는 유지한다.

## 진동: 정보 화면과 실제 화면/서비스 공통

| 상태 | 동작 | Android 파형(ms) |
| --- | --- | --- |
| 여유 있어요 | 진동 없음 | 없음 |
| 걸으세요 | 1회 | `[0,100]` |
| 놓칠 수 있어요 | 2회 | `[0,100,150,100]` |
| 뛰세요 | 3회 | `[0,100,150,100,150,100]` |
| 다음 차량 안내 | 끊김 없이 2초 연속 | `[0,2000]` |
| 정보 부족 | 진동 없음 | 없음 |

짧은 진동 사이의 150ms는 무진동 간격이다. 모든 파형은 반복하지 않는다.

`MovementVibration`은 횟수와 연속 진동을 구분한다. 정보 화면은 실제 상태→패턴 매핑의 설명을 사용하므로 별도 문구가 실제 구현과 어긋나지 않는다. 전면 화면과 서비스 모두 같은 파형 함수를 호출한다.

최초 상태 무진동, 변경 상태 3초 안정화, 진동 설정 OFF, 같은 상태 반복 무진동, 실제 발생 후 전역 30초 제한, 차단 이벤트 비축 없음은 유지한다. 여유 상태는 실제 진동 함수에 진입하지 않아 제한시각을 새로 소비하지 않는다. UI 상태는 진동 제한과 무관하게 즉시 바뀐다.

## 변경 파일

- `MainActivity.kt`: 요약 카드·모니터링 버튼 순서 및 보조 버튼 스타일 연결, 공통 진동 패턴 타입 사용.
- `PaceNudgeComponents.kt`: 한 줄 자동 크기 조정, 공통 `JourneyActionButton`.
- `MovementAdvice.kt`: 상태별 진동·파형 정의. 이동 판단 수식/임계값은 변경하지 않음.
- `JourneyMonitoringService.kt`: 공통 진동 호출 연결.
- `GuidanceInformation.kt`: 실제 진동 매핑에서 정보 화면 설명 생성.
- `ui_play.xml`, `ui_stop.xml`, `ui_refresh.xml`: Material 스타일 벡터.
- 기존 테스트 5개 파일: UI 순서/크기, 정보 화면, 패턴, Android Vibrator/서비스 회귀 기대값 갱신.

공식 ETA·시간표·GPS·지도·Worker API/예산/캐시 정책은 변경하지 않았다.
