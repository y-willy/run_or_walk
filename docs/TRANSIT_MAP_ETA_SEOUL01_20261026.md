# 지도·지하철 ETA·동대문01 연결 수정

## 적용 내용

- 지도에 현재 GPS→지정 출발지(파란색), 선택한 출발지→목적지 경로(초록색)를 표시한다.
  경로 제공자의 실제 구간별 좌표를 보존하며 없는 좌표를 직선으로 채우지 않는다.
  첫 경로는 도보 또는 접근 대중교통을 사용한다. 출발지와 GPS 35m 이동을 기준으로
  필요한 경로만 갱신하고, ETA 갱신은 지도 조회를 발생시키지 않는다.
- 두 경로를 처음 확보하면 전체 범위를 표시하고 지도 제스처·확대/축소 이후에는
  자동 카메라 초기화를 막는다. 사용자가 누른 내 위치 이동은 유지한다.
- 지하철은 공식 양수 ETA를 우선한다. 열차번호가 없으면 공식 방향·행선지·정차 순서와
  시간표로 후보를 좁혀 위치 기반 시간 범위를 계산한다. N번째 전역은 일반 열차의
  실제 정차 순서와 시간표 차이로 환산한다. 급행의 통과역을 정차역으로 간주하지 않는다.
  후보 운행일·급행 여부가 모호하면 하나로 확정하지 않는다.
- 이미 통과한 열차를 제외하고 원본 시각이 유효한 마지막 위치는 API 오류 중에도
  재사용한다. 위치 추정과 시간표 기준 시각은 실시간 ETA와 구분해 표시한다.
  화면·백그라운드 계산기와 기존 다음 차량 대기 정책을 사용한다.
- 정류장 첫 검색이 카카오만 조회하던 문제를 수정했다. ARS는 서울 공식 조회를
  직접 사용하고 이름 검색은 공식 버스 결과와 기존 지하철·장소 결과를 함께 제공한다.
  공식 선택 결과의 ID를 보존하고 요청 세대가 지난 응답은 새 결과를 덮어쓰지 못한다.
- 동대문01을 이름 예외 목록에 넣지 않는다. 미확인 버스는 서울 공식 조회부터 시작하고,
  공식 ID로 확인한 경기 제공기관 정보가 있으면 이를 우선한다. M5107의 GBIS 연결을 유지한다.
- 공백·쉼표·마침표·중점과 확인된 경희의료원/경희대의료원 정류소 별칭을 정규화한다.
  동대문01과 동대문A01은 서로 다른 이름·공식 ID로 유지한다.
- 자동 승차 방향은 terminal direction 문자열 대신 공식 stopId+stopOrder 이후에
  첫 버스 하차역(회기역)이 있는지 확인한다. 전체 목적지 수원역을 버스 하차역으로 쓰지 않는다.
- 방향 확인 중에도 공식 ETA는 표시한다. 경유정보 요청 실패·한도가 도착 API를
  불필요하게 막지 않도록 재시도 상태를 분리하고 공통 IP 제한은 지킨다.
- 이전에 저장한 자동 방향 확정은 경유 순서를 다시 확인한다. 선택 정류소·노선은 보존한다.

## 검증 구분

사용자가 제공한 실제 Worker JSON 원문을 Android 파서에 넣어 다음을 확인했다.

- 정류소 1개: 경희대의료원.경희여중고, ARS 06510, stopId 105900050, 좌표 정상.
- 노선 2개: 동대문01/105900003/순서4/유형2, 동대문A01/100000025/순서12/유형3.
- 정류소 검색 결과용 객체 변환, 이름·ARS 검색, 두 노선 분리 및 선택 상태 보존.

회기역이 순서 4 이후에 있는지, ETA 수신 후 걷기/빠른 걸음/다음 차량 판단은
별도의 모의 경유 순서·ETA로 재현했다. 실제 경유 순서 JSON과 도착 JSON을 확보했다는
뜻은 아니다. 이 환경의 직접 Worker 조회는 HTTP 403/Cloudflare 1010으로 차단됐다.

Android compileDebugKotlin·assembleDebug 성공, 저장소 외부 재현 검사 62건 통과.
Worker TypeScript 검사와 배포 dry-run도 성공했다. 테스트 소스·의존성을 저장소에
추가하지 않았다. 스마트폰의 지도 표시·제스처·화면 종료 알림은 아직 확인하지 못했다.

## 배포 필요

새 `/bus/route-stops?routeId=105900003`가 공식
`busRouteInfo/getStaionByRoute`를 조회한다. 기존 SEOUL_BUS_KEY를 사용한다.
이 변경에는 Worker 재배포와 APK 재빌드가 모두 필요하다. 운영 배포 성공은 별도 확인해야 한다.
새 경유 조회의 인증이 거부되면 해당 키의 서울 버스 노선정보조회서비스 권한을 확인해야 한다.

APK 경로: `app/build/outputs/apk/debug/app-debug.apk`.
