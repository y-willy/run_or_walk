# 동대문A01 현대코아 → 경희대 방면 연결 수정

사용자가 현대코아에서 경희대 서울캠퍼스 방면을 선택했을 때 경기 공식 연결 실패
메시지가 표시되는 문제를 조사했다.

## 확인된 코드 문제와 변경

- 모든 버스 경로가 GBIS 조회부터 시작했다. 서울시가 실제 운행을 공표한
  동대문A01·서대문A01·동작A01은 서울 공식 조회를 먼저 한다. 이것은 검색 우선순위이며
  공식 정류소·노선 ID 확인을 대체하지 않는다.
- 서울 정류소 조회에서 후보가 없거나 여러 개여도 이전 GBIS 실패 문구가 최종 안내로
  남았다. 서울 조회 시작 시 경기 요청 세대를 폐기하고 메시지를 지운다. 서울 인증·통신
  오류와 서울 정류소 없음·승차 방향 모호함을 각각 안내한다.
- 같은 이름의 양방향 정류소가 100m 이내에 둘 이상 있으면 자동 연결이 끝났다.
  최대 3개 공식 후보의 경유 노선을 확인해 같은 노선·공식 승차 순서·방향으로 하나가
  확인되는 경우만 연결한다. 거리가 가깝다는 이유만으로 반대편을 선택하지 않는다.
- 경희대의료원/경희의료원은 방향 표기에서 동일 기관의 별칭으로 비교한다.
  경희대 서울캠퍼스 전체를 의료원 정류소와 무조건 같다고 처리하지 않는다.
- 경로 찾기에서도 공식 연결을 확정하지 못하면 정류소·노선 선택 항목을 열 수 있다.

동대문A01의 A는 실제 노선명의 일부다. 동대문01과 합치거나 제거하지 않는다.
공식 조회로 얻은 ID만 사용하며 현대코아의 정류소 ID·ARS를 코드에 고정하지 않았다.

## 검증과 한계

Android Kotlin 컴파일·debug APK 생성 성공. 기존 검사와 신규 동대문A01 재현을 포함해
41건 통과(실패·오류 0). 신규 재현은 A 유지, 동대문01과 구분, 의료원 방향의 양방향
후보 구분, 방향 모호 시 자동 선택 금지, 이전 경기 오류·요청 세대 제거를 확인한다.
재현의 정류소·노선 ID는 합성값이며 실제 운영 ID를 확보한 것으로 보고하지 않는다.

운영 Worker의 `/bus/stops?query=현대코아`는 이 클라우드 환경에서 HTTP 403,
Cloudflare 1010으로 차단됐다. 실제 현대코아의 노선 목록·원본 routeType·ETA 수신은
확인하지 못했다. 이 수정으로 서울 API 키 권한이나 Worker WAF가 바뀌지는 않는다.

이번 변경은 Android 파일 3개와 이 문서다. Worker 코드는 변경하지 않았다.
최신 main을 받은 뒤 APK를 재빌드·설치해야 적용된다.
