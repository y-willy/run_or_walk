# 지도 인증 401 확인과 수정

`MAP_AUTHENTICATION:401`은 카카오 지도 서버가 앱 인증을 거절했다는 뜻이다. GPS 위치 권한과는 별개다. 네이티브 앱 키 오류, 다른 카카오 앱의 키 사용, Android 패키지·실제 서명 키 해시 미등록 등을 확인해야 한다. 401 코드만으로 이 중 어느 설정이 틀렸는지 단정할 수는 없다.

## 설치한 APK에서 확인

1. 지도 오류 카드의 **지도 인증 설정**을 누른다.
2. 표시된 패키지와 키 해시를 복사한다. 앱은 `PackageManager`에서 **지금 설치된 APK**의 현재 서명 인증서를 읽고 `Base64(SHA-1(certificate))`로 변환한다. API 키 원문은 표시하거나 복사하지 않는다.
3. **카카오 개발자 콘솔 열기**를 누르고, `local.properties`의 `KAKAO_NATIVE_KEY`가 속한 카카오 앱을 선택한다.
4. 해당 앱의 Android 플랫폼에 패키지 `com.example.run_or_walk`와 복사한 키 해시를 등록한다. 같은 카카오 앱의 **네이티브 앱 키**를 사용하고 있어야 한다. REST API 키를 지도 SDK에 넣으면 안 된다. 지도 서비스 사용 권한도 확인한다.
5. 콘솔 설정을 저장하고 앱에서 **재시도**한다. 키를 교체했다면 APK를 다시 빌드·설치한다.

Android Studio의 개인 디버그 서명, 이 클라우드의 디버그 서명, 배포용 서명, Play App Signing 서명은 다를 수 있다. 이전 값만 등록하거나 SHA-1의 16진수 문자열을 붙여 넣으면 실제 설치 APK와 일치하지 않는다. Play 배포는 업로드 키와 앱 서명 키도 구분한다.

현재 클라우드에서 생성한 디버그 APK를 `apksigner verify --print-certs`로 확인했을 때의 공개 키 해시는 `NzndnmLyMktPxFPPPbS6KfqJlV8=`이다. 이 값은 사용자의 PC 빌드에 그대로 적용된다고 가정하면 안 된다. **앱 안에서 표시된 값**을 우선한다.

## 이번 수정과 검증 범위

- 오류 카드에서 실제 설치 APK의 패키지·서명 키 해시를 확인하고 각각 복사할 수 있다.
- 지도 401을 네트워크·GPS 오류와 구분하고 정확한 설정 위치를 안내한다. SDK 원문 오류나 키·좌표는 로그에 남기지 않는다.
- 공식 SDK의 `499`는 네트워크 실패로 분류한다.
- 네이티브 키의 앞뒤 공백은 초기화 전에 제거한다.
- 이 작업 환경에서는 카카오 개발자 계정 설정을 읽거나 변경할 인증 수단이 없다. 따라서 원격 콘솔 등록 완료나 실제 스마트폰 지도 표시 성공을 주장하지 않는다. 위 등록은 카카오 앱 소유자 계정에서 수행해야 한다.

키 해시는 공개 APK 인증서에서 얻는 식별 정보이며 API 키와 다르다. 서명 개인키·비밀번호·API 키를 채팅이나 GitHub에 게시하지 않는다.

공식 근거: [Kakao Maps Android v2 지도 시작하기](https://apis.map.kakao.com/android_v2/docs/getting-started/quickstart/)의 인증 절차 및 `MapAuthException` 오류 코드 표.
